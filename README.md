# 포항 지역별 관광소비 모델링

지역과 업종의 소비를 하나의 공통 패턴으로 설명할 때 무엇을 놓치는지 살펴본 연구입니다. 서울·경기 자료에서 특징의 의미와 안정성을 먼저 검토하고, 포항 직접자료로 지역별 소비 기준선과 잔차 보정을 확장했습니다. 다른 지역에서 얻은 예측값이나 계수를 포항에 그대로 옮긴 모델은 아닙니다.

## 프로젝트를 시작한 이유

소비 규모가 큰 지역과 계절적으로 변화가 큰 지역을 같은 기준으로 비교하면, 규모 차이를 지역 고유의 특성으로 잘못 읽을 수 있습니다. 그래서 업종·시기별 정상 수준을 먼저 설명하고 남은 차이를 분석하는 두 단계 구조로 접근했습니다.

## 사용 기술

Python, pandas, NumPy, scikit-learn, CatBoost, SciPy, Matplotlib, PyYAML을 사용합니다. 표 형태의 소비·지역 특징에는 CatBoost를, 보수적인 잔차 보정 후보에는 Ridge·ElasticNet·Huber를 함께 둡니다.

## 데이터

서울·경기의 소비 및 지역 특성 자료는 특징 개념을 검토하는 donor입니다. 포항에서는 지역·업종·월 패널을 중심으로 관광소비, 연령구성, 기상, 계절성, 과거 소비 수준을 연결합니다. 기대소비 모델의 target은 로그 소비이며, 미래 월의 target이나 아직 끝나지 않은 집계창을 특징으로 사용하지 않습니다.

개별성 분석은 공통 배경을 제거한 잔차, 전년 대비 변화, 최근 추세, 계절 모양을 함께 봅니다. 원본 자료는 저장소에 포함하지 않으며 입력 구성은 [데이터 안내](data/README.md)에 정리했습니다.

## 모델 구조

```text
Donor 특징 진단 → 포항에 검토할 개념
포항 과거 패널 → Stage1 업종·지역·계절 기준선
                         ↓
                   실제 소비와의 잔차
                         ↓
               Bias 보정 + 중심화한 Structure 보정
                         ↓
                    기대소비와 차이
```

Stage1은 설명 가능한 정상 수준을 만들고, Stage2는 그 수준으로 설명되지 않은 부분만 보정합니다. 보정이 불안정하면 적용하지 않는 선택지도 모델에 포함합니다. 소비 차이는 조사 단서이지 특정 정책의 인과 효과가 아닙니다.

## 모델 발전 과정

### Donor → ablation → invariant

처음에는 서울·경기에서 특징 후보의 예측 기여와 coverage를 확인했습니다. 이후 특징군을 빼 보는 ablation으로 중요도가 단순 중복인지 살펴보고, invariant 단계에서는 조건이 달라도 유지되는 신호를 구분했습니다. Donor는 포항의 정답을 대신하는 데이터가 아니라 다음 실험의 가설을 좁히는 자료로 남겼습니다.

### 업종 기준선 → 동적 기준선 V2.1

정적 업종×월 기준선 뒤에 업종 ID를 다시 넣으면 일부 구간에서 예측이 좋아졌습니다. 기준선이 업종의 시간 변화를 충분히 흡수하지 못했다는 문제입니다. 최근 수준·추세·bias 보정 후보를 과거 내부 검증에서 경쟁시켰고, 기준선 오차뿐 아니라 뒤의 잔차 모델이 얻는 추가 정보도 함께 확인했습니다.

### 여러 검증창 V2.2 → 실현 가능성 V2.3

한 내부 검증창에서 고른 후보가 다른 시기에도 유효한지 보기 위해 여러 시간창을 사용했습니다. 연령×업종의 희소 특징이 업종 ID를 되풀이하는 문제에는, 업종의 과거 평균에서 벗어난 정도를 나타내는 dense deviation을 사용했습니다.

그럼에도 V2.3은 당시 결과에서 4개 fold 중 전체 실현 가능 조건을 만족한 fold가 없었습니다. 이 접근을 정책용 최종 모델로 채택하지 않고, 조건을 완화하는 대신 지역별 구조를 더 살펴보는 진단으로 남겼습니다.

### Individuality와 pilot → Stage2 V3

지역별 수준·계절 모양이 달라 공통 모델만으로 충분한지 다시 확인했습니다. Individuality와 지역별 scope 선택은 어떤 지역에 공통 구조를 유지하고 어디에 별도 보정이 필요한지 구분하는 방향입니다. Pilot 설계는 정책 효과를 확인하기 위한 별도 연구이며, 모든 실험이 하나의 확정된 직계 버전인 것은 아닙니다.

V3에서는 고정된 Stage1 위에서 여러 잔차 모델과 보정 강도를 비교하고, 안정성이 부족하면 보정을 생략했습니다. 보정을 항상 추가하는 것보다 “추가하지 않음”과 경쟁시키는 방식입니다.

### V3의 과도한 보정 → bias/structure V4

V3는 일부 fold를 개선했지만 다른 fold에서는 오히려 악화됐습니다. 후속 분석에서 구조 보정이 잔차와 잘 맞지 않으면서 전체 예측을 위로 밀어 올리는 문제가 나타났습니다.

V4는 일정한 수준 차이를 고치는 Bias와 특징에 따라 달라지는 Structure를 나눴습니다. Structure의 학습 예측 평균을 제거해 절편을 다시 학습하지 못하게 하고, 각 보정과 업종별 적용 여부를 독립적으로 선택합니다.

## 결과와 해석

보존된 V4 실험 기록의 최종 R² 중앙값은 약 0.8773, 최악 fold의 기준선 대비 변화는 약 −0.00285였습니다. 당시 허용된 비열등성 조건을 만족했지만 모든 fold에서 개선된 결과는 아닙니다. 소비 차이 분석과 정책 사용 허용도 별도로 다뤘습니다.

각 세대의 데이터·분할·기준선이 달라 숫자를 나란히 빼서 전체 성능 향상으로 해석하지 않습니다. 독립적인 정책 효과 검증과 장기 외부 검증은 남아 있습니다.

## 코드와 실행

[Donor core](src/pohang_donor_models), [설정](config), [후속 실험](experiments)을 구분해 읽습니다. 후속 실험은 서로 다른 패키지이며 일부 공통 모듈이 없어 전체 실험의 일괄 재현을 제공하지 않습니다.

```bash
pip install -e .
pip install -r requirements-dev.txt
python -m pohang_donor_models.cli --help
python -m pytest tests -q
```

실제 donor 계산에는 `config/default.yaml`에 맞는 입력 ZIP이 필요합니다.
