# 검증 결과를 읽는 기준

## 무엇을 비교했는가

모델 선택은 과거 inner window, 최종 성과 확인은 rolling outer fold로 나눕니다. Stage1, residual correction, interaction ablation은 같은 target이라도 비교 상대가 다릅니다. 데이터, split, 전처리, horizon과 metric이 모두 같은 비교에서만 변화량을 해석합니다.

## 보존된 주요 결과

| 단계 | 실험 기록 | 해석 |
|---|---|---|
| V2.1 / V2.2 | 일부 조건만 충족 | 다음 구조를 검토할 이유가 남음 |
| V2.3 | feasible fold 0/4 | 정책용 최종 모델로 채택하지 않음 |
| Individuality | 34 series, 2,368행, 72개월 범위 | 개별성 진단의 단위 |
| Individuality | 배경 절대상관 중앙값 약 44.6% 감소 | 예측 정확도 증가율이 아님 |
| V4 | 최종 R² 중앙값 약 0.877343 | 해당 rolling 평가의 결과 |
| V4 | 최악 gain 약 −0.002853 | 모든 구간에서 개선된 것은 아님 |

수치는 당시 실험 문서·결과에 보존된 값입니다. 서로 다른 세대를 한 표에 놓았다고 하나의 성능 순위가 되지는 않습니다. V4 gate 충족은 당시 허용한 비열등성·손해 제한을 만족했다는 의미이며 정책 사용이나 production 인증을 뜻하지 않습니다.

## 예측과 정책의 차이

기대소비와 관측소비의 차이는 후보 조사에 사용할 수 있지만, 그 차이가 특정 개입으로 회복 가능한 수요인지는 이 모델만으로 알 수 없습니다. Pilot은 효과를 검토하는 별도의 연구 가지로 봅니다.

## 코드 실행 범위

Donor core와 후속 실험은 실행 범위가 다릅니다. 일부 후속 실험의 공통 모듈과 원본 입력이 없어 전체 계보를 한 명령으로 재현할 수는 없습니다. [실행 안내](How-to-Run.md)에 경계를 적었습니다. 연산 테스트가 모델의 독립 외부 성능이나 정책 효과 검증을 대신하지 않습니다.
