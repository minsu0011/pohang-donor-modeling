# 검증과 해석의 경계

Donor core의 단위 테스트는 특징·연산의 기본 동작을 다룹니다. 후속 individuality 실험에는 `profiles`·`atlas` 공통 모듈이 없어 전체 실행을 재현할 수 없습니다. 다른 버전으로 대체하면 같은 실험이라고 볼 수 없습니다.

과거 V4 실험의 최종 R² 중앙값은 약 0.877343, 최악 fold 변화는 약 −0.002853입니다. 당시 비열등성 조건을 충족했지만 모든 구간의 개선이나 정책 효과 검증을 뜻하지 않습니다. V2.3도 정책용 최종 후보가 아닙니다.
