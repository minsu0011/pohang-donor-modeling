# 모델이 바뀐 이유

서울·경기 donor에서는 특징의 기여와 안정성을 검토했습니다. 포항에서는 업종의 시간 변화가 잔차에 남는 문제 때문에 동적 기준선을 도입하고, 단일 시기에 맞춘 선택을 줄이기 위해 여러 검증창으로 확장했습니다.

V2.3은 실현 가능 조건을 만족한 fold가 0/4여서 정책용 최종 모델로 채택하지 않았습니다. 개별성 분석과 별도 pilot 연구를 거쳐 V3에서 보정 생략을 후보로 넣었고, 일부 시기의 과도한 상향 보정 때문에 V4에서 Bias와 중심화한 Structure를 나눴습니다.

이 순서는 연구 질문의 발전입니다. 모든 실험이 단일 직계 버전은 아니며 서로 다른 데이터·분할의 점수를 개선율로 합치지 않습니다.
